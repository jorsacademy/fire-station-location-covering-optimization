# Capacitated Facility Location with Tabu Search in Julia

A self-contained Julia application example for the Capacitated Facility Location Problem (CFLP) using Tabu Search and a greedy customer-allocation heuristic.

The implementation is intended for educational, research, and noncommercial experimentation. It does not use a mathematical programming solver and does not claim global optimality.

## Problem

The problem contains:

- candidate facilities with fixed opening costs and capacities,
- customers with demand,
- transportation costs between facilities and customers,
- binary open/closed decisions for facilities,
- an assignment of every customer to one open facility without exceeding capacity.

The objective is to minimize:

```text
Total Cost = Facility Opening Cost + Customer Transportation Cost
```

## Solution Method

The outer search is a one-flip Tabu Search:

1. Start with all facilities open.
2. Generate neighbors by opening or closing one facility.
3. Reject infeasible neighbors.
4. Select the best admissible feasible neighbor.
5. Mark the moved facility tabu for a fixed tenure.
6. Override tabu status when the move improves the best solution found so far (aspiration criterion).
7. Keep the best solution encountered during the search.

For each facility configuration, customers are assigned using a greedy heuristic. Customers are processed in descending order of demand and assigned to the feasible open facility with the smallest transportation cost.

This inner assignment rule is heuristic. Therefore, even for a fixed set of open facilities, the reported assignment cost is not guaranteed to be the mathematically minimum possible assignment cost.

## Requirements

- Julia 1.10 or later

The implementation uses only Julia standard functionality and has no external package dependency for the optimization example.

## Run the Example

From the repository root:

```bash
julia --project=. examples/run_example.jl
```

The example creates a reproducible synthetic instance with:

- 10 candidate facilities,
- 20 customers,
- randomly generated facility and customer coordinates,
- random fixed opening costs,
- random capacities and customer demands,
- Euclidean distance as transportation cost,
- random seed `1234`.

The program reports iteration progress, the best objective value, the opening-cost and transportation-cost components, facility utilization, and customer assignments.

## Run the Tests

From the repository root:

```bash
julia --project=. -e 'using Pkg; Pkg.test()'
```

The tests check basic instance dimensions, feasibility of the all-open starting solution, capacity compliance, finite objective values, and objective-cost consistency.

## Important Modeling Note

This repository demonstrates a metaheuristic application rather than an exact CFLP solver. Tabu Search explores facility-opening decisions, while customer assignment is generated by a greedy heuristic. The best result should therefore be described as the **best solution found by the heuristic**, not as a proven global optimum.

For applications requiring optimality certificates, lower bounds, or exact customer assignment for each facility configuration, a MILP-based implementation using packages such as JuMP with an appropriate solver would be more suitable.
